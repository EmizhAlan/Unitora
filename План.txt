Да. Давай сразу зафиксируем **Unitora как реальный мини-продукт**, а не учебный проект. Цель — сегодня вывести MVP в интернет, в течение недели получить первые реальные посещения, а затем масштабировать то, что начинает работать.

# План разработки Unitora

## 0. Цель проекта

**Unitora** — бесплатный сайт с онлайн-конвертерами и калькуляторами.

Основная модель:

> Поисковый запрос → SEO-страница Unitora → пользователь решает задачу → видит рекламу → доход.

### Первая цель

Не «заработать много».

Первая цель:

**получить первые реальные деньги от реального пользователя.**

Даже если это будет `0,01 ₽`, система доказала, что работает.

# 4. Первый MVP

Не пытаемся сразу сделать 500 страниц.

Первый релиз:

### Конвертеры

**Длина**

* км → мили
* мили → км
* метры → футы
* футы → метры
* сантиметры → дюймы
* дюймы → сантиметры

**Вес**

* кг → фунты
* фунты → кг
* граммы → унции
* унции → граммы

**Температура**

* °C → °F
* °F → °C

**Скорость**

* км/ч → миль/ч
* миль/ч → км/ч

**Объём**

* литры → галлоны
* галлоны → литры

Получаем примерно **15–20 страниц**.

# 5. Как будет выглядеть страница конвертера

Далее:

```text
┌─────────────────────────────┐
```

Формула:

```text
1 км = 0.621371 мили
```

Ниже:

# 6. SEO

Это одна из самых важных частей проекта.

Каждая страница должна иметь собственные:

```text
title
description
h1
canonical
```

Например:

```text
Title:
Километры в мили — конвертер км в мили онлайн | Unitora

Description:
Быстро переведите километры в мили онлайн. Бесплатный конвертер км в мили с формулой и таблицей значений.
```

Но **не будем делать бессмысленные SEO-тексты ради количества слов**.

Страница должна реально отвечать на запрос пользователя.

# 9. Поиск

На сайте будет глобальный поиск.

Пользователь пишет:

```text
килограммы в фунты
```

Получает:

```text
Килограммы → фунты
```

Или:

```text
процент
```

Получает:

```text
Калькулятор процентов
```

На первом этапе поиск можно сделать полностью клиентским.

Никакой базы данных.

# 10. Реклама

Когда сайт будет готов:

**Яндекс → РСЯ.**

Размещаем рекламные блоки:

### На странице конвертера

```text
HEADER

Конвертер

[ калькулятор ]

──────────────
РЕКЛАМА
──────────────

Формула

Таблица

Похожие инструменты

РЕКЛАМА
```

Но **не заваливаем сайт рекламой**.

Нам нужно, чтобы пользователь действительно мог пользоваться сервисом.

```text

```

А для инструментов можно добавить события:

```text

```

Например:

> пользователь открыл калькулятор → ввёл значение → получил результат.

Это позволит понять, **какие инструменты реально используют**.

# 12. Яндекс Вебмастер

Главная задача:

**появиться в поиске Яндекса.**

**Не «сделать сайт и поставить рекламу».**

А:

> **создать полезный SEO-сервис → получить органический трафик → монетизировать его → анализировать данные → создавать больше востребованных инструментов → увеличивать трафик и доход.**

И я бы **не откладывал запуск ради идеального дизайна**. Сегодня делаем достаточно хороший MVP и **выводим Unitora в интернет в тот же день**. Остальное будем улучшать уже на живом проекте.
